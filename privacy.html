Política de Privacidad

Exclusivo para Loquendo Web Ecosystem & Discord Bots

Actualizado: Nov 2026

1. Datos Recopilados y Sin Base de Datos Externa

La plataforma Loquendo Web opera bajo un modelo sin almacenamiento persistente ni base de datos externa. Al utilizar el sistema de autenticación Discord OAuth2 (loquendo oauth), únicamente leemos en tiempo real desde la API de Discord:

  • ID único público de usuario de Discord.
  • Nombre de usuario y fotografía de perfil (avatar).
  • Estado de derechos de suscripción prémium (Entitlements) gestionados nativamente por Discord.

2. Procesamiento de Voz y Almacenamiento Local

Todo el texto ingresado en la interfaz para la síntesis de voz (Text-to-Speech) se procesa de forma directa e instantánea en la sesión de tu navegador mediante las Web Speech APIs o las voces integradas de la plataforma. No guardamos ni grabamos los audios o textos generados.

3. Integración con Discord Inc.

Toda la gestión de la identidad y de pagos para la aplicación prémium (loquendo premium) se realiza de forma directa mediante la API de Discord Inc. No compartimos, vendemos ni transferimos información a terceros.
